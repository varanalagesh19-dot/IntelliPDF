🚀 Netlify + Streamlit Deployment Blueprint

Why this two-tier architecture?

Netlify provides instantaneous global CDN hosting, high security, and custom domain SSL for your website. Meanwhile, Streamlit handles the heavy Python, FAISS vector indexing, and LLM inference engine.

Step 1: Deploy Streamlit App (Free)

Login to share.streamlit.io, select varanalagesh19-dot/IntelliPDF, set entry point to frontend/app.py and add secrets.

Step 2: Deploy to Netlify (Free)

Go to app.netlify.com ➔ Add new site ➔ Import from Git ➔ Choose IntelliPDF. Netlify uses netlify.toml automatically.
